# Critical Paths & Invariants (`CRITICAL.md`)

Load-bearing paths and non-negotiable production invariants for **`podcaster`** (`github.com/tvaroska/podcaster`). See [`AGENTS.md`](AGENTS.md) and [`DECISIONS.md`](DECISIONS.md).

| Path / Invariant | Why Irreversible / Critical | Pinning Test |
| :--- | :--- | :--- |
| **[`internal/app/app.go`](internal/app/app.go), [`internal/api/handlers.go`](internal/api/handlers.go) & [`internal/auth/auth.go`](internal/auth/auth.go) (Per-Show Isolation & 3-Tier Key Model)** | 1. Episodes with non-empty `podcast_id` belong exclusively to `/p/{id}/podcast.xml`, `/p/{id}/audio/{ep}.mp3`, and `/p/{id}/episodes/{ep}/chapters.json`; they must never appear on `/podcast.xml`, `/audio/{ep}.mp3`, or `/episodes/{ep}/chapters.json`.<br>2. Default-show listener credentials (`FEED_*`) and per-show listener credentials (`password` / `token` in `podcasts`) must never cross-authenticate.<br>3. **3-Tier Publisher Hierarchy**: **Super Key** (`ADMIN_API_KEY`, or `AGENT_API_KEY` when `ADMIN_API_KEY` is unset) creates/lists shows and manages all shows; **Default-Show Submitter** (`AGENT_API_KEY` when `ADMIN_API_KEY` is set) is scoped strictly to `podcast_id == ""`; **Per-Show Submitter** (`submit_key`) is scoped strictly to show `{id}` (`403` on other shows or `POST/GET /v1/podcasts`, and cannot read RSS/MP3/chapters).<br>4. `App.RotatePodcastCredentials` and `Store.UpdatePodcast` must persist updated `password`/`token` (and optional `submit_key`) while preserving `created_at` and returning `store.ErrNotFound` when missing.<br>5. `ListFilter{OnlyDefault: true}` must filter `podcast_id == ""` at the query level in both `SQLite.List` and `Firestore.List` before `LIMIT`. | [`internal/app/app_test.go`](internal/app/app_test.go) · [`internal/api/handlers_test.go`](internal/api/handlers_test.go) · [`internal/auth/auth_test.go`](internal/auth/auth_test.go) · [`internal/mcp/server_test.go`](internal/mcp/server_test.go) |
| **[`internal/store/sqlite.go`](internal/store/sqlite.go), [`internal/store/firestore.go`](internal/store/firestore.go) & [`deploy/firestore.indexes.json`](deploy/firestore.indexes.json) (SQLite & Firestore Parity)** | 1. Every `store.Store` method or filter must behave identically in SQLite and Firestore.<br>2. **SQLite Timestamp Ordering**: Format SQLite timestamps with fixed 9-digit zero-padded nanoseconds (`sqliteTimeLayout = "2006-01-02T15:04:05.000000000Z"`), never variable-width `time.RFC3339Nano` (where `"Z" > "."` misorders lexicographical `ORDER BY created_at DESC`).<br>3. **Firestore Preconditions**: `Firestore.Update` must check existence in a transaction (`store.ErrNotFound`, preserving `created_at`) and `Firestore.Delete` must use `firestore.Exists(true)`.<br>4. Multi-field Firestore query changes (`Where` + `OrderBy`) must stay synchronized across [`deploy/firestore.indexes.json`](deploy/firestore.indexes.json), [`deploy/bootstrap-gcp.sh`](deploy/bootstrap-gcp.sh), and [`docs/deployment.md`](docs/deployment.md). | [`internal/store/sqlite_test.go`](internal/store/sqlite_test.go) · [`internal/store/firestore_test.go`](internal/store/firestore_test.go) |
| **[`internal/worker/worker.go`](internal/worker/worker.go), [`internal/app/app.go`](internal/app/app.go) & [`internal/storage/gcs.go`](internal/storage/gcs.go) (Status Lifecycle, Reconcile & Immutable Audio Objects)** | 1. Internal statuses are `PENDING`, `PROCESSING`, `READY`, `FAILED`; external API/MCP responses map `PENDING` → `QUEUED` via `ep.PublicStatus()`, and `List` accepts both.<br>2. Workers claim episodes atomically via `Store.CompareAndSwapStatus` (`Worker.claim`) and write immutable `audio/<episode_id>.mp3` blobs.<br>3. **Cloud Run `Reconcile` Staleness Cutoff**: `App.Reconcile` enforces `WorkerTimeout` when `JOB_BACKEND=cloudrun` so scaling server instances never reset in-flight `PROCESSING` Cloud Run Jobs.<br>4. **Canceled Context Failure Persistence**: `Worker.fail` uses `context.WithoutCancel(ctx)` with a bounded timeout so `SIGTERM` / `WORKER_TIMEOUT` still persists `FAILED`.<br>5. **Enqueue Failure Recovery**: If `Jobs.Enqueue` fails in `App.CreateEpisode`, keep status `PENDING` (with `ErrorMessage` set) for `Reconcile` retry. | [`internal/worker/worker_test.go`](internal/worker/worker_test.go) · [`internal/app/app_test.go`](internal/app/app_test.go) · [`internal/storage/local_test.go`](internal/storage/local_test.go) |
| **[`Dockerfile`](Dockerfile), [`go.mod`](go.mod) & [`internal/tts/`](internal/tts/) (Pure-Go Zero-CGO, Distroless & Kokoro TTS Pipeline)** | 1. Production server binaries build with `CGO_ENABLED=0` (`GOARCH=amd64`) on `gcr.io/distroless/static-debian12:nonroot` (`65532:65532`) with writable `/data` pre-created via `--chown=65532:65532`.<br>2. `internal/tts` strips SSML/Markdown, splits text into `<= 500`-rune sentence-aware chunks, validates `VOICE_ALLOWLIST`, synthesizes WAV chunks via `sherpa-onnx-offline-tts` (`Kokoro-82M`), and masters 128 kbps 24 kHz mono MP3 to `-16 LUFS`. | [`internal/tts/preprocess_test.go`](internal/tts/preprocess_test.go) · [`internal/tts/kokoro_test.go`](internal/tts/kokoro_test.go) · [`internal/tts/ffmpeg_test.go`](internal/tts/ffmpeg_test.go) |
| **[`internal/config/config.go`](internal/config/config.go), [`internal/rss/rss.go`](internal/rss/rss.go) & [`internal/episode/validate.go`](internal/episode/validate.go) (Environment, Cloud Run, RSS GUID & Chapter Schema)** | 1.
